# Support

Use GitHub Discussions or Issues for installation, documentation, integration,
and feature questions. Include the Judge release/commit, Python version,
deployment mode, and a minimal reproducible configuration without credentials
or private task data.

For production operations, start with [the production profile](docs/production.md),
[node onboarding](docs/node-onboarding.md), and the [rollout checklist](docs/rollout.md).
For task-authoring questions, identify the task kind and run
`brunost task validate` before opening an issue.

Do not use public support channels for suspected vulnerabilities. Follow
[SECURITY.md](SECURITY.md) instead.
